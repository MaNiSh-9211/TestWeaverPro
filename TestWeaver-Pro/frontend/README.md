# TestWeaver Pro Frontend

A stunning glassmorphism-based React frontend for the TestWeaver Pro AI test automation system.

## 🚀 Features

- **Modern UI/UX**: Glassmorphism design with premium dark graphics
- **Authentication**: JWT-based authentication with context management
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Animations**: Smooth animations powered by Framer Motion
- **Form Validation**: Robust form validation with React Hook Form + Zod
- **State Management**: Zustand for global state management
- **API Integration**: Axios for backend communication

## 🛠️ Tech Stack

- **React 18** - Frontend framework
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **React Router** - Client-side routing
- **React Hook Form** - Form management
- **Zod** - Schema validation
- **Axios** - HTTP client
- **Lucide React** - Icon library
- **React Hot Toast** - Toast notifications

## 📦 Installation

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## 🎨 Design System

### Colors
- **Primary**: Blue gradient (#0ea5e9 to #0284c7)
- **Dark**: Dark slate (#0f172a to #334155)
- **Glass**: Semi-transparent overlays

### Components
- **Glass Effects**: Backdrop blur with transparency
- **Gradients**: Multi-directional gradients
- **Animations**: Smooth transitions and micro-interactions
- **Typography**: Inter + Poppins font combination

## 🔧 Configuration

### Environment Variables
Create a `.env` file in the root directory:

```env
VITE_API_BASE_URL=http://localhost:5000
VITE_APP_NAME=TestWeaver Pro
```

### Tailwind Configuration
The project uses a custom Tailwind configuration with:
- Extended color palette
- Custom animations
- Glass effect utilities
- Gradient backgrounds
